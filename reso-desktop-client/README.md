# RESO Desktop

The RESO desktop app for macOS, Windows and Linux: RESO certification, the Data Dictionary and any RESO Web API server
in one application.

- **Download:** [latest release](https://github.com/RESOStandards/reso-tools/releases/latest)
- **User guide:** [doc/GUIDE.md](doc/GUIDE.md), published at <https://tools.reso.org/guides/reso-desktop-client/>

The app's source is kept in a private repository. This folder holds its public user guide and the guide's
screenshots.
